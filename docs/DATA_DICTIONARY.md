# NeuroGraph-DB Data Dictionary

**Status:** Approved Phase 2 relational design with the implemented Phase 5 batch-analysis extension. PostgreSQL is the intended store, SQLAlchemy 2.x the ORM, and Alembic owns schema changes.

Notation: `PK` primary key; `FK` foreign key; `UQ` unique; `NN` not null. Unless stated otherwise, IDs are `BIGINT GENERATED BY DEFAULT AS IDENTITY`, timestamps are `TIMESTAMPTZ` in UTC. Proposed identifiers avoid SQLAlchemy/Pydantic reserved namespace collisions by using `architecture_config` and `review_metadata`.

## 1. `roles`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `role_id` | BIGINT | No | PK | Internal role key. |
| `role_key` | TEXT | No | UQ; canonical uppercase | Stable authorization code. |
| `display_name` | TEXT | No |  | Human-readable name. |
| `description` | TEXT | Yes |  | Role purpose. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Creation time. |

One role is assigned to each user in this draft. Role deletion is `RESTRICT` while assigned.

## 2. `users` — application login identities

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `user_id` | BIGINT | No | PK | Internal app actor key. |
| `role_id` | BIGINT | No | FK → `roles`, index | Assigned role. |
| `email` | TEXT | No |  | Display email. |
| `email_normalized` | TEXT | No | UQ; CHECK equals `lower(btrim(email))` | Canonical login identity. |
| `username` | TEXT | Yes | UQ after normalization when present | Optional handle. |
| `password_hash` | TEXT | No | Argon2id preferred; never returned | One-way password hash only. |
| `is_active` | BOOLEAN | No | default true | Disable access without deleting history. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Account creation time. |
| `updated_at` | TIMESTAMPTZ | No |  | Last profile/security update. |
| `last_login_at` | TIMESTAMPTZ | Yes |  | Last successful login. |

Users are not review authors. Role deletion is restricted; user deletion cascades to session tokens and sets nullable actor FKs to null in historical rows. Routine account removal should be deactivation plus session revocation.

## 3. `session_tokens` — revocable sessions

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `session_token_id` | UUID | No | PK | Opaque session identifier. |
| `user_id` | BIGINT | No | FK → `users` ON DELETE CASCADE; index | Owning login account. |
| `access_jti_hash` | CHAR(64) | No | UQ; lowercase SHA-256 hex | Digest of the access token's JWT ID; do not store access token. |
| `refresh_token_hash` | CHAR(64) | No | UQ; lowercase SHA-256 hex | Digest of opaque refresh token; do not store refresh token. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Session issuance time. |
| `last_used_at` | TIMESTAMPTZ | Yes |  | Last accepted use. |
| `access_expires_at` | TIMESTAMPTZ | No | CHECK later than `created_at` and no later than refresh expiry | Access credential expiry. |
| `refresh_expires_at` | TIMESTAMPTZ | No | CHECK later than `created_at` | Refresh credential expiry. |
| `revoked_at` | TIMESTAMPTZ | Yes |  | Logout/revocation time; non-null makes session invalid. |
| `replaced_by_session_id` | UUID | Yes | FK → `session_tokens`, `SET NULL` | Session created during rotation, if any. |

Store only hashes/JTI digests, never plaintext bearer or refresh tokens. Authentication validates signature/expiry and checks the active session digest so logout/revocation invalidates access. Refresh rotates credentials transactionally and revokes the prior session. Index `(user_id, refresh_expires_at)` and partial index active sessions where `revoked_at IS NULL`.

## 4. `reviewers` — review authors, not app accounts

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `reviewer_id` | BIGINT | No | PK | Internal author key. |
| `source_system` | TEXT | No | UQ pair | Dataset/source namespace. |
| `external_reviewer_key` | TEXT | No | UQ pair | Source author identifier; pseudonymize when appropriate. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | First import time. |

Unique `(source_system, external_reviewer_key)`. A reviewer has zero or many reviews. Unknown reviewer remains nullable on a review.

## 5. `products`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `product_id` | BIGINT | No | PK | Internal product key. |
| `source_system` | TEXT | No | UQ pair | Dataset/source namespace. |

| `display_name` | TEXT | Yes |  | Product name when available and permitted. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | First import time. |

Unique `(source_system, external_product_key)`. A product has zero or many reviews. Product deletion sets review FK null to preserve historical reviews.

## 6. `reviews`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `review_id` | BIGINT | No | PK | Internal review key. |
| `source_system` | TEXT | Yes | UQ pair when set | Source namespace; null for local rows. |
| `source_review_key` | TEXT | Yes | UQ pair when set | External review identifier. Standard name across the design. |
| `reviewer_id` | BIGINT | Yes | FK → `reviewers`, index | Review author; distinct from app user. |
| `product_id` | BIGINT | Yes | FK → `products`, index | Reviewed product. |
| `submitted_by_user_id` | BIGINT | Yes | FK → `users`, index | App account that submitted/imported the row. |
| `rating` | SMALLINT | Yes | CHECK 1–5 when present | Source rating. |
| `reviewed_at` | TIMESTAMPTZ | Yes |  | Event time from source. |
| `review_text` | TEXT | Yes |  | Content subject to source licensing and retention. |
| `ground_truth_label` | SMALLINT | Yes | CHECK in `{0,1}` | Curated/evaluation label, not a model prediction. |
| `label_source` | TEXT | Yes |  | Provenance for known ground-truth label. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | DB insertion time. |
| `updated_at` | TIMESTAMPTZ | No |  | Last permitted edit. |

**Required source-consistency CHECK:** `(source_system IS NULL) = (source_review_key IS NULL)`. Thus both source fields are null for local rows or both are set for imported rows. Partial unique `(source_system, source_review_key)` applies when both are non-null. Do not enforce uniqueness by review text.

Delete is restricted while a review appears in retained graph snapshots, predictions, or feedback; use an approved retention/de-identification workflow. `reviewer_id`, `product_id`, and `submitted_by_user_id` use `SET NULL` on referenced identity removal.

## 8. `preprocessing_versions`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `preprocessing_version_id` | BIGINT | No | PK | Immutable preprocessing registry key. |
| `version_key` | TEXT | No | UQ | Human-readable immutable version identifier. |
| `preprocessing_sha256` | CHAR(64) | No | UQ; lowercase SHA-256 hex | Hash of canonical preprocessing code/config manifest. |
| `preprocessing_config` | JSONB | No | default `{}` | Tokenizer, embedding, feature, normalization and input-contract settings. |
| `code_revision` | TEXT | No |  | Source commit/revision for the preprocessing implementation. |
| `lifecycle_status` | TEXT | No | CHECK `registered`, `verified`, `retired`, `unavailable` | Verification state. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Registration time. |
| `verified_at` | TIMESTAMPTZ | Yes |  | Verification time. |

Version key functionally determines its checksum/config. One preprocessing version may be referenced by many model versions. Checkpoint compatibility is verified before a model version is usable.

## 9. `model_versions`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `model_version_id` | BIGINT | No | PK | Model registry key. |
| `version_key` | TEXT | No | UQ | Immutable model version label. |
| `model_name` | TEXT | No | index | Architecture family. |
| `architecture_version` | TEXT | No |  | Code/API compatibility version. |
| `architecture_config` | JSONB | No | default `{}` | Validated inference configuration. |
| `config_sha256` | CHAR(64) | No | lowercase SHA-256 hex | Hash of canonical architecture config. |
| `checkpoint_uri` | TEXT | Yes | Required before `verified` | Immutable artifact location. |
| `checkpoint_sha256` | CHAR(64) | Yes | UQ when present; lowercase SHA-256 hex | Exact weight identity. |
| `preprocessing_version_id` | BIGINT | No | FK → `preprocessing_versions`, index | Preprocessing identity; checksum is stored only in referenced table. |
| `input_contract_version` | TEXT | No |  | Expected feature/graph contract. |
| `supported_inference_mode` | TEXT | No | CHECK `known_node_only` until another mode is verified | Capability declaration. |
| `recommended_threshold` | NUMERIC(8,7) | Yes | CHECK `[0,1]`; required before `verified` | Per-checkpoint operating threshold. Not a calibration assertion. |
| `threshold_source` | TEXT | Yes | Required with threshold | Validation artifact/run reference. |
| `lifecycle_status` | TEXT | No | CHECK `unavailable`, `registered`, `verified`, `retired` | Only verified model is selectable. |
| `provenance` | VARCHAR(30) | No | default `real`; CHECK `real`, `synthetic_demo`; demo cannot be `verified` | Separates production evidence from UI/demo provenance. |
| `verification_at` | TIMESTAMPTZ | Yes |  | Verification time. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Registration time. |

A verified row must have resolvable checkpoint, verified preprocessing, input contract, and validation-derived threshold/source. This cross-field rule belongs to registry verification logic. Model/preprocessing records are immutable once referenced by runs.

## 11. `graph_snapshot_reviews`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `graph_snapshot_id` | BIGINT | No | PK part; FK → `graph_snapshots`, `ON DELETE CASCADE` | Snapshot membership. |
| `review_id` | BIGINT | No | PK part; FK → `reviews`, `ON DELETE RESTRICT` | Review present in the snapshot. |
| `split` | TEXT | No | CHECK `train`, `validation`, `test` | This review's partition within this exact snapshot. |

Composite PK `(graph_snapshot_id, review_id)` ensures one split assignment per review per snapshot. Index `(graph_snapshot_id, split, review_id)` supports split-scoped lookups; reverse index `(review_id, graph_snapshot_id)` supports review history. This table is the membership authority for prediction validation.

|---|---|---:|---|---|

| `graph_snapshot_id` | BIGINT | No | FK → `graph_snapshots`, index | Pinned graph/split identity. |
| `requested_by_user_id` | BIGINT | Yes | FK → `users`, index | App actor; null for system-originated runs. |

| `inference_mode` | TEXT | No | CHECK `known_node_only` until verified otherwise | Supported inference scope. |
| `threshold` | NUMERIC(8,7) | No | CHECK `[0,1]` | Exact decision threshold pinned to run. |
| `threshold_source` | TEXT | No |  | Validation artifact/config provenance. |
| `status` | TEXT | No | CHECK `queued`, `running`, `succeeded`, `partial`, `failed`, `cancelled` | Run lifecycle. |

**Idempotency:** unique `(requested_by_user_id, idempotency_key)` where key is non-null; CHECK `idempotency_key IS NULL OR requested_by_user_id IS NOT NULL`. System runs may omit both. Before privileged hard deletion of an actor, clear both actor FK and key transactionally; normal policy is account deactivation. User-requested runs pin one threshold and snapshot; model/checkpoint/preprocessing provenance follows FKs.

## 15. `graph_sync_jobs`

| Column | Type | Null | Key / rule | Meaning |
|---|---|---:|---|---|
| `graph_sync_job_id` | BIGINT | No | PK | Projection job key. |
| `operation` | TEXT | No | CHECK `review_upsert`, `review_delete`, `snapshot_rebuild` | Operation and scope are coupled by CHECK constraints below. |
| `review_id` | BIGINT | Yes | FK → `reviews`, `RESTRICT` | Review-scoped source; retain job scope until job history is resolved. |
| `graph_snapshot_id` | BIGINT | Yes | FK → `graph_snapshots`, `RESTRICT` | Snapshot-scoped rebuild source. |
| `requested_by_user_id` | BIGINT | Yes | FK → `users`, `SET NULL` | Requesting app actor, if user-originated. |
| `idempotency_key` | TEXT | Yes | UQ with requesting user when present | User/API retry key. |
| `source_event_key` | TEXT | Yes | Global UQ when set | Internal outbox event key; distinct from user idempotency. |
| `status` | TEXT | No | CHECK `queued`, `running`, `succeeded`, `retry_wait`, `failed`, `cancelled` | Job lifecycle. |
| `attempt_count` | INTEGER | No | CHECK `>= 0`, default 0 | Retry count. |
| `max_attempts` | INTEGER | No | CHECK `> 0` | Retry cap. |
| `next_attempt_at` | TIMESTAMPTZ | Yes | Partial index for due work | Retry schedule. |
| `created_at` | TIMESTAMPTZ | No | default `now()` | Queue time. |
| `started_at` | TIMESTAMPTZ | Yes |  | Last/current start. |
| `completed_at` | TIMESTAMPTZ | Yes |  | Terminal time. |
| `last_error_code` | TEXT | Yes |  | Sanitized error code. |
| `last_error` | TEXT | Yes |  | Sanitized diagnostic; no secrets. |

**Required scope CHECK:** `(operation IN ('review_upsert','review_delete') AND review_id IS NOT NULL AND graph_snapshot_id IS NULL) OR (operation = 'snapshot_rebuild' AND review_id IS NULL AND graph_snapshot_id IS NOT NULL)`. This prevents mixed or empty scope. User idempotency is unique `(requested_by_user_id, idempotency_key)` when key is present, with CHECK that key requires user. Internal `source_event_key` remains globally unique for outbox deduplication. Retry preserves both keys; `attempt_count` and most recent error are retained here. Before privileged user deletion, clear requester FK and key transactionally. Add an attempt-history table only if a later requirement calls for every attempt's details.

## Index and constraint summary

| Table | Important indexes/checks |
|---|---|
| `roles` | UQ `role_key`. |
| `users` | UQ `email_normalized`; partial UQ normalized username; `(role_id, is_active)`. |
| `session_tokens` | UQ access/refresh digests; `(user_id, refresh_expires_at)`; partial active-session index. |
| `reviewers` | UQ `(source_system, external_reviewer_key)`. |
| `products` | UQ `(source_system, external_product_key)`. |
| `reviews` | source-pair nullity CHECK; partial UQ `(source_system, source_review_key)`; rating/label checks; `(product_id, reviewed_at)`, `(reviewer_id, reviewed_at)`, `(ground_truth_label)`, `(created_at)`. |
| `review_variants` | UQ `(review_id, variant_key)`; index `variant_type`. |
| `preprocessing_versions` | UQ `version_key`, checksum; lifecycle check. |
| `model_versions` | UQ version/checkpoint hashes; `preprocessing_version_id` FK/index; threshold range/source; index `(model_name, lifecycle_status)`. |
| `graph_snapshots` | UQ snapshot/artifact hashes; nonnegative counts; `(dataset_name, created_at DESC)`. |
| `graph_snapshot_reviews` | Composite PK `(graph_snapshot_id, review_id)`; split check; `(graph_snapshot_id, split, review_id)`; reverse `(review_id, graph_snapshot_id)`. |
| `inference_runs` | Threshold/count/status/mode checks; scoped UQ `(requested_by_user_id, idempotency_key)`; `(status, created_at)`, `(model_version_id, created_at DESC)`, `(graph_snapshot_id, created_at DESC)`. |
| `fraud_predictions` | Score check; UQ `(inference_run_id, review_id)`; `(inference_run_id, predicted_label)`, `(review_id, created_at DESC)`. |
| `review_feedback` | Controlled type/status, label check; scoped UQ `(submitted_by_user_id, idempotency_key)`; `(review_id, created_at DESC)`, `(status, created_at)`. |
| `graph_sync_jobs` | Exclusive scope CHECK; scoped user idempotency UQ; global UQ source event; partial due-work index; `(status, created_at)`. |
| `audit_logs` | Action check; `(occurred_at DESC)`, `(actor_user_id, occurred_at DESC)`, `(entity_type, entity_key, occurred_at DESC)`, request ID. |
| `batch_analyses` | Status/count checks; unique batch UUID and optional unique inference-run link; `(created_at)`. |
| `batch_analysis_rows` | Accepted/rejected FK CHECK; unique `(batch_analysis_id, row_number)`; `(batch_analysis_id, row_state, row_number)`. |

Use `RESTRICT` for provenance-bearing history, `CASCADE` only where child rows have no independent meaning (review variants and sessions), and `SET NULL` for optional actors/identities whose historical records must survive. See [ERD.md](ERD.md) for full cardinalities and deletion rationale.
