# Data and model provenance audit

Updated 31 October 2026. This document distinguishes the current verified models from an earlier synthetic prototype.

## Current real-data evidence

- The deployed inductive model uses 47,176 labelled raw reviews with the recorded source fingerprint and chronological split.
- The matched four-model comparison reuses the same input tensors, split membership and validation-selection rule. Each recorded run has checkpoint, prediction and training-log fingerprints.
- The structured MAT and earlier raw multimodal runs remain historical records with their own data/protocol. They are excluded from the matched ranking.
- Model bundles and raw datasets are local/private dependencies rather than checked-in runtime substitutes.

See [model card](MODEL_CARD.md), [controlled comparison](benchmarks/README.md) and [run records](runs/).

## Superseded synthetic results

The older 5,000-node `artifacts/graph/yelpchi_graph.pt` was generated by `ml/mock_data.py`. Its numeric/semantic features and graph links depend on generated labels. Earlier near-perfect clean, ablation and camouflage tables therefore do not measure real Yelp fraud detection. Placeholder rewritten text and embedding perturbations also do not establish resistance to actual LLM rewrites.

Those tables have been replaced with links to measured real-data results. Obsolete model/graph binaries are kept out of the source snapshot. The legacy embedding script now raises an error if RoBERTa fails instead of silently substituting label-conditioned random vectors. Synthetic generators remain clearly identified as fixture utilities, not data acquisition.

## Claim boundaries

The measured metrics establish performance only under the recorded dataset and protocol. A file fingerprint proves file identity, not classification correctness. Attention weights are not causal explanations. Equal train/test membership permits a controlled architecture comparison, but model parameter counts and input modalities intentionally differ. Report metric-specific outcomes and training variation without guaranteeing a universal winner.
